# SQL Exercise 1 – SELECT & Filtering

## About
This repository contains my submission for Exercise 1: "SQL Fundamentals: SELECT & Filtering." 
The exercise covers 10 handwritten SQL queries based on a single `employees` table, focusing on 
retrieving, sorting, and filtering data.

## Contents
- `SQL-Exercise-1.pdf` – scanned handwritten SQL queries with expected output tables

## Topics Covered
- Retrieving data with `SELECT` (all columns and specific columns)
- Removing duplicates with `DISTINCT`
- Sorting results with `ORDER BY`
- Limiting results with `LIMIT`
- Filtering rows with `WHERE`, combining conditions using `AND`, `OR`, `NOT`, and `IN`
